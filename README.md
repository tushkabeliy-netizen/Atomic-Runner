# Atomic Runner

A Godot 4 Android endless-runner prototype inspired by Soviet retrofuturism.

## Current status

This repository is being prepared for the first playable prototype. The initial milestone is a three-lane runner with swipe controls, jumping, sliding, collectible tokens, and a procedural industrial city backdrop.

## Build status

No APK has been built or tested yet. The Android export workflow will be added after confirming the required GitHub Actions permissions.
